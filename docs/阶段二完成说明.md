> 「作答页只能鼠标点选；全项目监听键盘的只有演示窗口（空格 / 左右方向键 / Esc）」。

## 一、按键表

| 键 | 作用 |
|---|---|
| `1`-`5`（主键盘） | 选第 N 个选项 |
| `1`-`5`（小键盘） | 同上 |
| `A`-`E` | 同上。选项左边的角标是 1-5，两套键指向同一个位置 |
| `Enter` / 小键盘 `Enter` | 答完进入下一题 |
| `Esc` | 退出本轮，回到进来那一页 |

几条刻意这么定的规则：

- **只在桌面端接键盘**：`PlatformTarget.isDesktop` 为假时 `_handleKey` 第一行就
  `ignored`，手机上等于没这个功能，外接键盘也不会出现「半套操作方式」
- **只认 `KeyDownEvent`**：`KeyRepeatEvent` 一律忽略，按住 Enter 不放不会连着跳题
- **没作答时按 Enter 什么都不做**：返回 `handled` 但不动状态。否则手滑一下就把这题
  当成跳过记进错误统计，比不做更糟
- **越界的键吃掉**：本题只有 4 个选项时按 `5`，返回 `handled` 但不作答 ——
  不往上传，免得被上层的焦点导航接走变成「跳焦点」
- **`Esc` 不判对错、也不补记录**：答过的题早就落库了，退出只是不再往下答；
  成绩单页上也一样能按 `Esc` 退出
- 不用猜键位：题目下方有一行提示，**按本题实际选项数生成**
  （4 个选项就写「键盘：1-4 或 A-D 选答」）

## 二、怎么实现的

- 新增 `lib/src/ui/quiz_keys.dart`，只有三个纯函数：
  `quizOptionIndexForKey` / `isQuizNextKey` / `isQuizExitKey`。
  不碰 Riverpod、不判断平台，所以能直接单测
- `lib/src/ui/pages/quiz_page.dart` 从 `ConsumerWidget` 改成 `ConsumerStatefulWidget`，
  外面包一层 `Focus(autofocus: true, onKeyEvent: _handleKey)`：进页面就能直接用键盘，
  不用先点一下页面
- **逻辑层一行没动**：选项下标、正误判定、限时、自动翻页全都还是原来的
  `QuizController`，键盘只是换了个入口去调 `answer()` / `next()`
- 平台判断只在 UI 层（架构约束），`quiz_keys.dart` 里连平台判断都没有
