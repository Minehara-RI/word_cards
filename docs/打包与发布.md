# 打包与发布

> 一句话：**跑 `scripts\build_release.ps1`**，产物全在 `dist\`。
> 本文记录每一步在做什么、产物长什么样、以及踩过的坑。

## 一、产物清单

| 文件 | 给谁 | 怎么用 |
|---|---|---|
| `dist\word_cards-1.0.0.apk` | 安卓手机 | 传到手机点开装（需要允许「安装未知来源应用」） |
| `dist\word_cards-setup-1.0.0.exe` | Windows 电脑 | 双击安装，带开始菜单与桌面快捷方式、可卸载 |
| `dist\word_cards-win-x64.zip` | 不想装东西的人 | 解压直接跑 `word_cards.exe` |
| `dist\word_cards-win-x64\` | 同上的目录版 | 免安装 |

> `1.0.0` 来自 `pubspec.yaml` 的 `version:`，打包脚本自己读，
> 不用手改；要发新版就改 `pubspec.yaml` 再重跑。

## 二、一条命令

```powershell
pwsh -File scripts\build_release.ps1
```

它按顺序做四件事：

1. `scripts\verify.ps1` —— `flutter analyze` + `flutter test` + Windows 集成测试；
2. `scripts\build_apk.ps1` —— release APK；
3. `scripts\build_windows.ps1` —— release 免安装目录 + zip；
4. `scripts\build_installer.ps1` —— 用 Inno Setup 打成单文件安装包。

赶时间可以跳步：

```powershell
pwsh -File scripts\build_release.ps1 -SkipVerify      # 不跑测试
pwsh -File scripts\build_release.ps1 -SkipInstaller   # 不出安装包
```

## 三、工具链（换机器只改一处）

所有路径集中在 `scripts\env.ps1`，别的脚本 dot-source 它：

```powershell
$env:PUB_CACHE        = 'D:\ProgramData\pub-cache'
$env:JAVA_HOME        = 'D:\ProgramData\jdk-21'
$env:ANDROID_HOME     = 'D:\ProgramData\android-sdk'
$env:GRADLE_USER_HOME = 'D:\ProgramData\gradle-home'
```

这些**没有写进用户环境变量**（避免污染系统），所以脚本自带一份。

另外两样是系统级安装的，脚本会自动找：

- **Inno Setup 6** —— 打 Windows 安装包用。本机是 `winget install JRSoftware.InnoSetup` 装的，
  落在 `%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe`（装 `Program Files` 时脚本也认）。
  没装的话 `-SkipInstaller` 只出 zip。
- **Android SDK 28.2 的 NDK** —— `sqlite3_flutter_libs` 要编译原生库。

### Gradle 代理是个坑

本机 Gradle 走的是 `127.0.0.1:7897` 的本地代理（配置在 **`D:\ProgramData\gradle-home\gradle.properties`**，
刻意**不放进仓库**，免得把本机代理写进版本控制）：

```properties
systemProp.https.proxyHost=127.0.0.1
systemProp.https.proxyPort=7897
```

代理没开的时候，release 构建会在下载 Flutter 引擎产物
（`io.flutter:arm64_v8a_release`）时失败，报
`Connect to 127.0.0.1:7897 failed: Connection refused`。

两个办法，任选：

- **把代理打开**（推荐，本机一直这么用）；
- 或者临时注释掉那两行代理配置 —— 但**必须先把 Gradle 守护进程停掉**，
  否则它还在用启动时读到的旧 JVM 属性，改了文件也不生效：

  ```powershell
  cd android; .\gradlew.bat --stop; cd ..
  ```

  Gradle 的 `systemProp.*` 是守护进程启动时固化的，**光改文件不重启守护进程 = 没改**。

国内镜像兜底在 `D:\ProgramData\gradle-home\init.d\aliyun-mirrors.gradle`，
把阿里云的 google / public / gradle-plugin 三个仓库插到最前面，同样是机器级配置、不入库。

## 四、Android 说明

- **包名** `com.minehara.word_cards`，**minSdk / targetSdk** 用 Flutter 的默认值
  （见 `android\app\build.gradle.kts`）。
- **签名**：`release` 目前**用 debug 签名**（Flutter 模板原样，`signingConfig = signingConfigs.getByName("debug")`）。
  自己装机 / 发给朋友完全够用 —— 是合法签名，只是不是发布到应用商店的那种。
  真要上架再建 keystore：
  `keytool -genkey -v -keystore upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload`，
  然后在 `android\key.properties` 里写路径与口令（**这两样都已在 `.gitignore` 里，不会入库**），
  最后把 `build.gradle.kts` 的 `signingConfig` 换成读 `key.properties` 的 `release` 配置。
- 通用包 58 MB 是正常的：里面带了 `arm64-v8a` / `armeabi-v7a` / `x86_64` 三个 ABI 的
  SQLite 原生库。只装自己手机想要小一点，可以
  `pwsh -File scripts\build_apk.ps1 -Split` 出三个分 ABI 的包，装对应那个（通常 20 MB 上下）。

## 五、Windows 说明

- 产物是 **x64**、**release** 构建。
- **按用户安装，不弹 UAC、不要管理员密码**（`PrivilegesRequired=lowest`，
  Inno 于是把 `{autopf}` 映射到 `%LOCALAPPDATA%\Programs`），装到：

  ```
  C:\Users\<你>\AppData\Local\Programs\word_cards
  ```

  装完从开始菜单（「单词卡片」）启动；勾了「创建桌面快捷方式」才有桌面图标。
  想装给全机器用的人，可以自己加 `/ALLUSERS`（已开
  `PrivilegesRequiredOverridesAllowed=commandline`）。
- **卸载不碰用户数据**：数据在 `%APPDATA%\com.minehara\word_cards\collection.anki2`，
  `[UninstallDelete]` 只清安装目录里的 `data\`。
  已验证：装 → 跑 → 卸载，安装目录与开始菜单清干净，`collection.anki2` 原样保留。
- 安装包做了**简体中文界面**，但官方 Inno Setup 不自带中文语言文件 ——
  `packaging\word_cards.iss` 里用 `#if FileExists(...ChineseSimplified.isl)` 判断，
  装了语言包就出中文，没装就自动退回英文，**不会因此编译失败**。
- 应用图标取 `windows\runner\resources\app_icon.ico`。

## 六、目录约定

```
scripts/                 打包与体检脚本（入版本库）
  env.ps1                工具链路径，唯一需要按机器改的文件
  verify.ps1             analyze + test + 集成测试
  build_apk.ps1          Android
  build_windows.ps1      Windows + zip
  build_installer.ps1    Inno Setup
  build_release.ps1      一条命令出齐
packaging/               安装包定义（入版本库）
  word_cards.iss         Inno Setup 脚本
dist/                    产物（不入版本库，见 .gitignore）
```

## 七、发布前自查

1. `pubspec.yaml` 的 `version:` 改好了吗（它决定产物文件名与安装包版本）；
2. `pwsh -File scripts\build_release.ps1` 全绿；
3. 手机上装 APK，跑一遍「加入 → 作答 → 统计 → 导出」；
4. 电脑上装安装包，跑一遍同样的四页 + 演示页；
5. `dist\` 里的东西**不进版本库**（已在 `.gitignore`）。
