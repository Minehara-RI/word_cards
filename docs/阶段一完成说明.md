## 一、交付内容

### 1. 数据层（sembast 本地库）

| 文件 | 职责 |
|---|---|
| `data/local/app_database.dart` | 开库/关库、store 定义；支持内存库（测试用） |
| `data/local/sembast_card_repository.dart` | 卡片增删改查、按单词查重（写入时补 `word_key` 归一化字段） |
| `data/local/sembast_record_repository.dart` | 答题记录，按时间倒序，支持按时间过滤 |
| `data/local/sembast_deck_repository.dart` | 词库（阶段五才做 UI，数据层已就位） |
| `data/local/sembast_settings_repository.dart` | 单文档配置 |

数据落在系统给应用的数据目录（Windows 下是 `%APPDATA%\com.minehara\word_cards\word_cards.db`），
不连任何服务器。

### 2. 容错 JSON 解析器（阶段一的技术核心）

`data/import/card_parser.dart` 面向「大模型不会老老实实只输出 JSON」这个现实：

- 剥掉 Markdown 代码块（自动挑最长的那个块）、BOM、零宽字符
- 前面有「好的，下面是你要的卡片：」后面有「还需要别的吗？」也能截取出中间那段 JSON
- 字段名中英文混用都能认：单词侧接受 word / term / text / 单词 / 词 / headword，
  释义侧接受 definition / meaning / answer / correct / 释义 / 意思 / 中文释义
- 结构变体：顶层对象、顶层数组、包一层 `cards/data/items/结果` 都行；
  只给了 `options` 加 `answerIndex` 也能还原出正确项并把干扰项挑出来
- 语法修复：尾随逗号、`//` 与 `/* */` 注释、全角逗号冒号、
  中文引号被当成字符串定界符、字符串里未转义的换行
- **错误必须具体**：报错形如「第 2 张卡片：缺少 definition（正确释义）字段」；
  整段语法错误会给「第 N 行第 M 列附近」并附上下文片段

修复只在字符串**外部**动结构字符，字符串内容原样保留 —— 所以释义里的中文标点不会被误伤。

### 3. 导入服务

`data/import/import_service.dart` 在解析之后做：

- 批内去重（同名单词只留第一张）并提醒
- 与本地已有卡片比对，默认跳过重复，可选择覆盖（覆盖不会新增行）
- 干扰项不足 4 个时，从同批其它卡片的释义里借，凑满 5 个选项
- **部分失败不影响其余**：好的进库，坏的逐条报告

### 4. 逻辑层（纯函数，无 Flutter 依赖）

- `logic/quiz.dart`：出题（选项去重、补足 5 个、可传随机种子复现）、答题后更新掌握度
- `logic/stats.dart`：概览统计；投影模式的答题不计入个人成绩

### 5. UI

| 页面 | 能力 |
|---|---|
| 首页 | 学习概览（卡片总数/已掌握/今日答题/总正确率/掌握进度条）、开始测验、各入口 |
| 导入卡片 | 3 套 Prompt 模板切换、一键复制、**粘贴即实时校验**、解析预览、导入结果报告 |
| 快速测验 | 单词+音标+词性、5 个选项、即时对错反馈、自动下一题、手动下一题、反应时间计时 |
| 本轮结果 | 正确率、答对题数、平均反应时间、错题清单、再来一轮 |
| 卡片列表 | 搜索、掌握度色点、来源标签、练习次数/正确率/平均反应、编辑、删除（含侧滑） |
| 设置 | 每轮题数、主题、清空卡片 / 清空记录 |

### 6. 每题限时（硬规则）

- `AppSettings.questionTimeLimitSeconds`：默认 10 秒，设置页提供 5/10/15/20/30 秒档位，
  **刻意没有「不限时」开关**
- `QuizController` 用 1 秒一跳的定时器驱动倒计时：到点即走超时分支，
  写入一条 `timedOut: true` 的错题记录（`reactionMs` 等于限时），然后自动进入下一题
- 作答会立刻取消倒计时，同一题不会被重复记账；超时后这一题的选项点击不再生效
- `AnswerRecord` 新增 `timedOut` 字段，成绩单与错题清单会单独标出来
- 倒计时**只更新整秒**而不是每帧动画：高频重建会让 widget 测试与真机集成测试里的
  `pumpAndSettle` 永远等不到静止状态
- 「每题限时」这个设置项与设置页文案都明说了：课堂投影模式按同一原则走

### 7. 正误显示时机（三选一）

`AnswerRevealMode` 三档，共用同一套答题与计时逻辑，只改「什么时候把答案说出来」：

| 模式 | 答题过程中 | 结束后 |
|---|---|---|
| `immediate` 立即显示（默认） | 选项立刻标绿/标红，底部给出正确释义 | 列出答错的单词 |
| `deferred` 统一显示 | 不露任何对错，只中性标出「你选了这一项」 | 逐题回顾：你选了什么 + 正确答案 |
| `never` 不显示 | 同上 | 只给总分，不列题目与答案 |

实现要点：

- `QuizState.showCorrectness` = 已作答 且 模式为立即显示；选项配色、底部提示条都只看它
- 非立即显示时，选项用**中性主色**标记「你选了这一项」，绝不用绿/红泄露对错
- 非立即显示时会**隐藏右上角的实时「答对 N 题」**：这个计数会间接暴露上一题做对没有
- 翻页节奏也跟着变：立即显示留 850ms（超时 1600ms）让人看清答案；
  统一/不显示只留 260ms，没什么可看的
- 逐题回顾靠「作答与题目一一对应」直接按下标配对，不需要往答题记录里冗余存单词

## 三、本阶段真正修掉的 bug

端到端测试和手测过程中发现并修复：

1. `_itemsOf` 把嵌套卡片数组 `{cards:[{...}]}` 里的对象 `toString()` 成了字符串，导致整包导入失败
2. `_repair` 在字符串内部没把中文右引号当成结束引号，全角引号场景修复不出来
3. `computeStats` 在跳过投影模式之前就累加了 `totalCorrect`，集体复习污染了个人正确率
4. 「返回首页」只 `pop()` 一层：从导入页直接开测验时会退回导入页而不是首页，改成 `popUntil(isFirst)`
5. 导入按钮的转圈和结果弹窗重叠导致转圈停不下来；改成先停转圈再弹结果
