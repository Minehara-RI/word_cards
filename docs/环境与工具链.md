## 二、已写入的用户级环境变量

- `JAVA_HOME` = `D:\ProgramData\jdk-21`
- `ANDROID_HOME` / `ANDROID_SDK_ROOT` = `D:\ProgramData\android-sdk`
- `PUB_CACHE` = `D:\ProgramData\pub-cache`

  `D:\ProgramData\android-sdk\platform-tools`、`D:\ProgramData\android-sdk\cmdline-tools\latest\bin`

## 三、网络

外网走 Clash Verge 混合端口 `http://127.0.0.1:7897`。

- `D:\ProgramData\gradle-home\gradle.properties`：配了系统属性代理 + 连接超时兜底
- `D:\ProgramData\gradle-home\init.d\aliyun-mirrors.gradle`：机器级 Gradle init 脚本，
  给所有构建追加阿里云镜像（google / public / gradle-plugin），代理挂掉时仍能构建。
  **刻意不放进工程仓库**，免得把本机网络配置提交上去。

注意：代理节点偶尔会整片失效（dl.google.com、repo1.maven.org 一起不通），
阿里云镜像始终可用，所以 Android 链路不依赖代理也能跑通。

## 四、Windows 侧的两个一次性开关

1. **开发者模式**（必须）：Flutter 带原生插件时要在构建目录建符号链接，
   否则报 `Building with plugins requires symlink support`。
   已通过 UAC 提权写注册表打开：
   `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\AppModelUnlock\AllowDevelopmentWithoutDevLicense = 1`
2. **Android SDK licenses**：已用 `sdkmanager --licenses` 全部接受。

## 七、额外装的包（换成 Anki 数据库那一轮加的）

| 包 | 用途 | 备注 |
|---|---|---|
| `sqlite3` | Anki 数据库（SQLite） | 3.7.x 已经改用 Dart native assets 自己编译 SQLite，所以 `flutter test` 在 Windows 上直接就能开库（实测 libVersion = 3.54.0），不用再单独塞 dll |
| `crypto` | 算 Anki 的 `csum`（sha1 前 8 位十六进制） | 纯 Dart，无原生代码 |
| `audioplayers` | 演示模式的翻页提示音 | 需要 3000 Hz / 0.5 秒的自定义波形，`SystemSound.play` 做不到，所以只能走音频插件 |
| `file_selector` | 演示模式里挑「自选提示音」的音频文件 | flutter.dev 官方插件，Windows 与 Android 都支持；Windows 用扩展名过滤，Android 用 MIME 类型，所以 `XTypeGroup` 两个都填 |

> `sqlite3_flutter_libs` 的最新版带 `+eol` 后缀（因为 sqlite3 3.x 已经自己带库了）。
> 它和 native assets 路线并存不会冲突，装上只是多一层保险。

Windows 上做界面截图与点击用的是 `D:\ProgramData\_shots\ui.ps1`（不在仓库里）：

- 坐标是**物理像素**：Windows 缩放 150%，Flutter 的逻辑坐标要乘 1.5
- 本机屏幕是 2560x1600；窗口开到 1626 高时底部会被任务栏压住，
  想截到页面最底部（例如全屏演示的播放控制条）要把窗口调矮一点（1200 左右）
