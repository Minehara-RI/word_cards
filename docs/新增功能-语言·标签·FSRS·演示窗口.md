# 新增功能：语言 / 标签 / 卡组 / FSRS-6 / 独立演示窗口

> 这一轮加的东西：**五种语言的单词**、**卡片标签**、**单一当前卡组**、
> **可选的 FSRS-6 复习算法**、**演示模式另开一个强制最大化的窗口**、
> **统一无衬线字体**，以及**所有设定都会被记住**。

## 一、语言支持（英 / 法 / 日 / 韩 / 俄）

![设置里的语言与字体](screenshots/27-设置-外观与语言字体.png)

- 语言是**单词本身的语种**，共五种：英语 English / 法语 Français / 日语 日本語 /
  韩语 한국어 / 俄语 Русский
- 设置页选「新词默认语言」；加入页和导入页也能就地改，三处共用同一个值（改完就记住）
- 语言存在 Anki 的标签里：`lang::en`、`lang::fr`、`lang::ja`、`lang::ko`、`lang::ru`。
  这样拿 Anki 打开也一眼能看出这张卡是哪国语言的词
- 复制给大模型的 Prompt **会跟着语言变**：模板里的「英语词汇教研员」「美式音标」
  「英文例句」会替换成对应语言的说法，音标那一栏也换成本语言的习惯写法：
  - 英语 → 美式音标 `/əˈbændən/`
  - 法语 → 国际音标 `[a.bɑ̃.dɔ.ne]`
  - 日语 → 平假名读音【すいえい】
  - 韩语 → 罗马字 `[sagwa]`
  - 俄语 → 国际音标 `[ɐtkɐˈzatʲsə]`
- 卡片列表会显示语言徽章，搜索也能按语言名匹配

## 二、标签

![加入页的标签与语言](screenshots/25-加入-卡组标签与语言.png)

![导入页的整批标签](screenshots/26-导入-整批标签与卡组选择.png)

- **单张卡打标签**：加入页的「标签（逗号分隔，可留空）」
- **整批打标签**：导入页的「整批标签」——这一批词一起打上，和卡片自己的标签合并去重
- **已有的标签可以点一下就用**：加入页会列出当前卡组里出现过的标签，按出现次数排序
- 标签最后写进 Anki 的 `notes.tags`，和来源、语言放在一起：
  ` 手动导入 lang::ja N2 第1课 `
- 空档处理：标签里的空白会换成下划线（Anki 的标签不能带空格），
  `lang::xx` 这种语言标签不会被当成用户标签
- 卡片列表每条都显示标签小徽章，搜索时标签也参与匹配

### 标签也用来定「这一轮考哪些词」

![作答页的作答范围与标签筛选](screenshots/29-作答-标签筛选与全部.png)

- 作答页「本轮设置」里多了一排**标签筛选**（FilterChip），候选就是当前卡组里出现过的标签，
  按出现次数排序，和加入页用的是同一套规则（lib/src/logic/study_pool.dart）
- 规则：**一个都不选 = 当前卡组全出；选了多个 = 词要同时带上这些标签（与）**
- **只在「原有算法」下显示与生效**：挂着 FSRS-6 时这一排标签**整块不画**
  （复习队列按整个卡组排，摆出来只会误导）；选择照样留在设置里，
  切回「原有算法」立刻又出现、立刻生效
- **非 FSRS 的默认出题范围就是当前卡组的全部词**：
  「题目数量」里的「全部」不再写死一个数字（存的是 0，即 AppSettings.allQuestions），
  卡组加词之后会自己跟着长；想少做仍然可以点 5 / 10 / 20 题
- 「只练做错过 / 正确率低的词」那条路也吃同一个筛选
- 筛完一个词都不剩时，开始按钮直接禁用，并提示「按标签筛完一个词都不剩了」

## 三、卡组：所有新词进同一个「当前卡组」

![卡组条](screenshots/25-加入-卡组标签与语言.png)

规则很简单：**新加入的词都进当前卡组，只有你主动换组或开新组时才换卡组。**

- 加入页 / 导入页 / 设置页顶部都有同一条「当前卡组」栏，三处看到的是同一个状态
- 「更换卡组」在对话框里选（含「全部词库」）；「开启新卡组」让你起个名字，
  建完立刻变成当前卡组
- 当前卡组记在设置里（`active_deck_id`），下次打开还是它
- **导入时给两个选择**：「合并到当前卡组（N 张）」或「放入新卡组…」，
  后者先问名字，再把这批词落到新卡组里 —— 老卡组的词一张都不动

## 四、FSRS-6：可选的复习算法（与原有算法互不干扰）

![作答页的复习算法](screenshots/24-作答-本轮设置与FSRS.png)

- 作答页「复习算法」二选一：**原有算法**（按正确率 / 掌握度挑词）或 **FSRS-6**
- **算法用现成的**：直接依赖 pub.dev 上的官方包
  [fsrs](https://pub.dev/packages/fsrs)（open-spaced-repetition/dart-fsrs，21 个参数 = FSRS-6），
  `lib/src/logic/fsrs.dart` 里只有一层适配：状态映射 + 评分映射 + 复习队列，
  公式一行都没有重写，将来升级算法只要换包版本
- **评分怎么来**：作答结果映射到 Again / Hard / Good / Easy ——
  超时或答错 = Again；答对按用时：≤40% 限时 = Easy，≤75% = Good，再慢 = Hard
- **目标保留率**可以调（80% / 85% / 90% / 95%）：调高 → 复习更勤、间隔更短
- 打开 FSRS 后，「只练做错过 / 正确率低的词」按钮旁边多一个
  「复习今天到期的词（N）」，只挑今天真正到期的（含没学过的新词）
- **独立性**：FSRS 的记忆状态（稳定性 / 难度 / 到期时间）单独存在
  `wc_card_fsrs` 表里，掌握度 / 正确率 / interval_days / ease_factor 那套照旧由
  原来的逻辑维护。开着 FSRS 只写新表，换回原有算法时新表原样留着，
  两边都不认识对方，谁也不覆盖谁
- 参数：用官方 dart-fsrs 包自带的 FSRS-6 参数（`kFsrs6DefaultParameters`），
  不自己训练、也不抄别的应用的参数（理由见
  [FSRS参数优化.md](FSRS参数优化.md)）；要试别的参数集，
  给 `FsrsConfig(parameters: [...21 个...])` 传一组即可，格式不对会自动退回默认值
- 学习步长刻意留空（`learningSteps: []`）：本应用一轮里一个词只答一次，
  不需要「1 分钟 / 10 分钟」这种当天内的学习步骤，首次作答后直接按稳定性给天数

## 五、演示模式：另开一个强制最大化的窗口

![独立演示窗口](screenshots/22-演示-独立窗口最大化.png)

「演示」**只有桌面端有**：课堂投影是「一台电脑接投影仪」的场景，
手机既开不了独立的演示窗口，也没法把画面投给一屋子人，所以手机端
主界面只有四个入口（加入 / 作答 / 统计 / 导出），「演示」整页不给 ——
页面、入口、设置页里那套演示深浅色一起不出现。

点「开始演示」之后：

- 桌面端**新开一个系统窗口**专门放演示画面（主窗口不被打断），
  **并且强制最大化**：开机就最大化，被还原的话两秒内自动再最大化回去
- 演示窗口里只有画面，**没有任何可点的按钮**；空格暂停/继续、
  左右方向键上一题/下一题、Esc 退出 —— 这些按键会回传给主窗口处理
- 主窗口这时显示「演示已在另一个窗口播放」+「停止演示」；
  **直接关掉演示窗口就等于停止演示**，主窗口会停掉这一轮并照常写出答案 txt

### 为什么要这么分层

主窗口是唯一的「真相来源」：算题、控节奏、翻页提示音、写答案 txt 都在主窗口，
它每秒把当前一帧（题目 / 序号 / 剩余秒数 / 暂停状态）推给演示窗口，演示窗口只负责画。
好处是：

- 只有一个定时器和一份状态，不会出现两个窗口各算各的、时间对不上
- 翻页提示音、答案文件这些带副作用的逻辑不用在第二个引擎里再实现一遍
- 独立窗口开不出来时（插件不可用、测试环境）自动退回应用内全屏页，行为一致
- 手机端连这一路都没有：手机上不显示「演示」页，演示那套设置也就无从打开

### 强制最大化是怎么做到的

第二个窗口是 desktop_multi_window 起的**另一个 Flutter 引擎**，
那个引擎里只注册了插件自己的平台通道 —— 实测 `window_manager` 之类在子窗口里
会直接报 MissingPluginException。所以最大化改成直接调 user32.dll：
子窗口的窗口类是 `FLUTTER_MULTI_WINDOW_WIN32_WINDOW`（和主窗口的类名不同），
用 `FindWindowW` 按类名找到它，再 `ShowWindow(SW_MAXIMIZE)`；
关闭窗口用 `PostMessage(WM_CLOSE)`。见 `lib/src/ui/presentation/presentation_win32.dart`。

## 六、所有设定都会被记住

存在 `wc_settings` 表里（一条 JSON），下次打开逐项恢复：

| 分类 | 记住的内容 |
|---|---|
| 界面 | 主界面深浅色、**演示模式单独的深浅色**、字号缩放、**上次停在哪个页面** |
| 词库 / 语言 | 当前卡组、新词默认语言 |
| 作答 | 每轮题数（含「全部」）、**标签筛选**、每题限时、正误显示时机、复习算法、FSRS 目标保留率 |
| 演示 | 每题停留、选项编号（12345 / ABCDE）、随机顺序、循环、每轮重排、 |
|  | 提示音开关 / 频率 / 时长 / 内置或自选音频、答案文件输出模式与目录 |
| 导入 | 上次选的 Prompt 模板 |
| API | 地址 / 密钥 / 模型 / 超时 / 缓存时长（阶段三用） |

## 七、字体：统一无衬线 + 演示模式大字

- 全应用统一到一套**无衬线字体栈**（`lib/src/ui/fonts.dart`）：
  Windows 用 Microsoft YaHei UI，拉丁 / 西里尔由主字体覆盖，
  日文假名、韩文谚文用 Yu Gothic UI / Malgun Gothic 兜底；Android 走系统 sans-serif + Noto CJK。
  设置页有一行「英语 abandon 法语 abandonner 日语 すいえい 韩语 사과 俄语 отказаться」
  可以当场看出有没有掉字形
- 演示模式另有一套大字号（单词 76、选项 34、倒计时 40），加粗、放宽字距，
  投影到教室最后一排也看得清
